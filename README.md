## ✦ Overview

A portfolio website crafted for **Diya Nathwani**, Content & Brand Strategy Consultant for founders, brands, and creators.

Features editorial layout design inspired by tactile print magazines, vibrant paper textures, bold typography, and smooth interactive micro-animations.

---

## ✦ Key Features

- **Paper Aesthetic & Grain Texture**: Full-bleed `#f4eee3` newsprint paper background with subtle SVG noise texture and editorial border framing.
- **Lenis Smooth Scroll**: Butter-smooth inertial scrolling synced with GSAP.
- **GSAP & ScrollTrigger Engine**:
  - Live 3D flipping hero taglines (`DATA x DRAMA`, `ICONIC HOOKS`, etc.).
  - Staggered card entrance reveals and stamp animations.
  - Floating ambient tilts on stage and studio photography.
- **Real-Time Live IST Clock**: Live Indian Standard Time ticker with quirky status commentary.
- **7 Work Drawers (58 Projects)**:
  - Dynamic category switching (Campaigns, Social Media, B2B SaaS, Pop-culture, Creative Writing, Podcasts, Websites).
  - **Concise by Default**: Clean preview displaying lead card + balanced grid row.
  - **Expandable / Collapsible**: Interactive button to explore full drawers and collapse smoothly back.
- **Interactive Accordions**: Single-open animated accordion for services and FAQs.
- **Journey Timeline**: 4 interactive chapters (Corporate, Clients, Education, Milestones).
- **Social Proof**: Infinite client logo marquee and drag-enabled testimonials carousel.

---

## ✦ Tech Stack

- **Markup**: Semantic HTML5 with accessibility attributes and OpenGraph metadata
- **Styling**: Vanilla CSS3, custom properties, responsive CSS grid, flexbox, tactile drop-shadows
- **Animation & Physics**: [GSAP 3.12](https://gsap.com/) & [ScrollTrigger](https://gsap.com/scrolltrigger/)
- **Smooth Scroll**: [Lenis 1.1](https://lenis.darkroom.engineering/)
- **Typography**: Antonio, Space Grotesk, Plus Jakarta Sans, Caveat, Inter

## ✦ Getting Started

Clone the repository and run any static file server:

```bash
# Clone repository
git clone https://github.com/gtxPrime/diya.git
cd diya

# Serve locally
python -m http.server 8080
# or
npx serve .
```

Open `http://localhost:8080/` in your browser.
